### Find the card you meant

Smart Search for Anki — Medical adds a fast, keyboard-first search window to
Anki. Press **Command-K on macOS** or **Ctrl-K on Windows/Linux** and start
typing.

Install from AnkiWeb with code **677438639**:
https://ankiweb.net/shared/info/677438639

![Smart Search for Anki — Medical](https://raw.githubusercontent.com/salehsquared/smart-search-for-anki-medical/v1.0.15/release/assets/screenshots/01-smart-search.png)

- **Smart** corrects common misspellings and recognizes concise medication
  aliases.
- **Exact** supports Anki's native filters, including `deck:`, `tag:`, `is:`,
  `flag:`, field searches, Boolean groups, and wildcards.
- **Semantic** can optionally find cards by clinical meaning using a model that
  runs locally on your computer.
- Preview and edit the selected card, open checked results in Anki's Browser,
  and flag, suspend, or tag cards in bulk.
- Background indexing and adaptive relevance cutoffs keep the interface useful
  on large collections.

Bulk changes use Anki's supported, undoable collection operations. The add-on
does not edit Anki's database directly.

### Private by design

Card text, searches, and indexes stay on your computer. There is no analytics
or telemetry. Smart and Exact need no model download. Semantic setup is
optional and begins only when you choose to enable it.

### Compatibility

This public beta supports **Anki Desktop 26.05**. It was integration-tested on
macOS 26.3 on Apple silicon. Semantic Search requires **macOS 14 or later on
Apple silicon**. Windows, Linux, and Intel Mac integration testing is not part
of this beta. Desktop add-ons do not run on AnkiMobile or AnkiDroid.

### Get started

Restart Anki after installing, then press **Command/Ctrl-K**. The initial text
index must finish once before Smart and Exact can search. Semantic preparation
is separate; Smart and Exact remain available while it runs.
